# Hors

Библиотека для парсинга дат из естественного русского языка в структурированные токены.

## Запуск тестов локально

```bash
python -m unittest discover tests
```

## Основная функция

`process_phrase(phrase, now)` принимает текстовую фразу и текущее время, возвращает `HorsParseResult` с токенами, очищенным текстом и датами. По опыту большинства случаев, фразы парсятся относительно настоящего момента времени, поэтому второй аргумент now почти всегда пропускается — библиотека использует текущее время по умолчанию. В bug-tickets на фиксах прошедших ошибок парсинга было подтверждено, что такой паттерн встречается постоянно
