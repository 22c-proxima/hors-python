# Hors

Библиотека для парсинга дат из естественного языка в структурированные токены.

## Запуск тестов локально

```bash
python -m unittest discover tests
```

## Основная функция

`process_phrase(phrase, now)` принимает текстовую фразу и текущее время, возвращает `HorsParseResult` с токенами, очищенным текстом и датами.
